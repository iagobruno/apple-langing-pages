# Apple Landing Pages

Projeto de estudo que busca replicar (manualmente sem IA) o estilo de design e as animações 3D com scroll das landing pages do site da Apple.

## Tecnologias utilizadas

- Nuxt
- Vue
- GSAP
- TailwindCSS
- Lenis (scroll suave)

## Como executar localmente

```bash
bun install
bun run dev
```
